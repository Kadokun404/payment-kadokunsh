Dokumentasi API Gateway

Integrasikan sistem pembayaran QRIS GoPay dinamis ke website, bot WhatsApp, bot Telegram, atau aplikasi mobile kamu dalam hitungan menit.

🔑

Autentikasi Header

Semua request API wajib menyertakan header token autentikasi. Ambil tokenmu di Dashboard Merchant.

x-internal-token: YOUR_SECRET_API_TOKEN
POST

/api/gopay/create

Membuat Dynamic QR Code

Menghasilkan kode QRIS dinamis berstandar EMVCo GoPay sesuai nominal pesanan.

Request Body (JSON):

{
  "amount": 25000
}

Response (200 OK):

{
  "status": true,
  "ref_no": "TRX-KDK-829104",
  "amount": 25000,
  "qr_content": "00020101021226670014ID.GO-JEK...",
  "expires_in": 300
}
GET

/api/gopay/status

Cek Status Mutasi Masuk

Mengecek apakah dana transfer pembeli sudah berhasil masuk ke rekening merchant.

Query Parameters:

GET /api/gopay/status?ref=TRX-KDK-829104&amount=25000

Response (200 OK):

{
  "paid": true,
  "ref": "TRX-KDK-829104",
  "amount": 25000,
  "settlement_time": "2026-11-10T09:28:10Z"
}
POST

/api/gopay/cancel

Membatalkan Tagihan

Membatalkan sesi pembayaran yang kedaluwarsa atau dibatalkan oleh pembeli.

Request Body:

{
  "ref": "TRX-KDK-829104"
}

Contoh Kode Integrasi (Node.js)

import fetch from "node-fetch";

async function createPayment(amount) {
  const res = await fetch("https://qris.kadokunn.com/api/gopay/create", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-internal-token": "YOUR_API_TOKEN"
    },
    body: JSON.stringify({ amount })
  });

  const data = await res.json();
  console.log("QRIS String:", data.qr_content);
  console.log("Nomor Referensi:", data.ref_no);
}

createPayment(25000);
