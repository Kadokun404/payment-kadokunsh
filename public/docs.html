Dokumentasi API JSON

Integrasikan sistem pembayaran QRIS GoPay dinamis ke website, bot WhatsApp, bot Telegram, atau aplikasi kamu dalam 5 menit.

🔐 Autentikasi API

Setiap permintaan HTTP wajib menyertakan header x-internal-token. Kamu bisa mendapatkan token merchant di halaman Dashboard.

Headers: x-internal-token: kado_live_xxxxxxxxxxxx Content-Type: application/json
POST /api/gopay/create

Membuat kode QRIS dinamis untuk tagihan nominal tertentu. Mengembalikan string QR, nomor referensi unik, dan nominal bayar.

Request Body (JSON):
{ "amount": 25000 }
Response (200 OK):
{ "ok": true, "ref_no": "TRX-KDK-829141", "amount": 25000, "qr_content": "00020101021226670014ID.GO-JEK.WWW011893600914...", "expires_in": 300 }
GET /api/gopay/status

Mengecek status apakah tagihan sudah dibayar oleh customer via mutasi GoPay.

Query Parameters:
GET /api/gopay/status?ref=TRX-KDK-829141&amount=25000
Response (200 OK):
{ "ok": true, "paid": true, "ref": "TRX-KDK-829141", "amount": 25000, "settlement_time": "2026-11-10T09:25:00.000Z" }
🚀

Webhook Realtime Callback

Jika kamu mendaftarkan URL Webhook di dashboard, server QRIS Kadokun akan otomatis menembak HTTP POST ke website toko kamu begitu pembayaran berhasil!

POST https://tokokamu.com/api/qris-callback Content-Type: application/json { "event": "payment.success", "ref": "TRX-KDK-829141", "amount": 25000, "status": "PAID", "paid_at": "2026-11-10T09:25:00Z" }

💻 Contoh Kode (Node.js / Express)

// Buat Tagihan QRIS via Node.js async function createInvoice(amount) { const response = await fetch("https://qris.kadokunn.com/api/gopay/create", { method: "POST", headers: { "Content-Type": "application/json", "x-internal-token": "kado_live_xxxxxxxxxxxx" }, body: JSON.stringify({ amount }) }); const data = await response.json(); console.log("QRIS String:", data.qr_content); return data; } createInvoice(50000);
